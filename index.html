ระบบบันทึกภาพและพิกัดลงมือถือไว้แล้ว กดส่งข้อมูลเมื่อมีเน็ต

ข้อจำกัดทางเทคนิคและคำแนะนำ:

  • ระบบแปลงเสียง (Speech to Text): ทำงานได้แม่นยำดีเยี่ยมใน Google Chrome และ Safari หากเสียงแวดล้อมดังเกินไป ระบบแปลงเสียงอาจเพี้ยน ให้แก้ไขพิกัดและป้อนตัวเลขด้วยปุ่มกดบนหน้าจอทดแทนได้
  • การใช้พิกัดแผนที่: ตัวหมุดย้ายปรับแบบ LINE จะใช้ Leaflet Map ซึ่งฟรีและเร็ว หากต้องการอัปเกรดเป็น Google Maps API ในภายหลังจะเริ่มมีค่าใช้จ่ายเมื่อเกินโควตาฟรี
  • การตั้งค่า Google Apps Script: เพื่อทำการรับข้อมูลบันทึกรูปภาพไปที่ Google Drive และข้อความไปที่ Google Sheets อย่างเต็มระบบ คุณต้องตั้งค่าตัวรับ API หลังบ้านก่อน (คู่มืออยู่ในโค้ดและส่วนท้ายคำอธิบาย)
